# Web App

Premium Next.js (App Router) dashboard for members, trainers, and admins.

## Structure

```
src/
  app/
  components/
  context/
  hooks/
  layouts/
  types/
  utils/
```

## Running locally

1. `cp .env.example .env.local`
2. `npm install`
3. `npm run dev`

Update `NEXT_PUBLIC_API_BASE_URL` in `.env.local` with your API base URL.
